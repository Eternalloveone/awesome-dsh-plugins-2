# 数据集说明 / Dataset Notes

本目录保存 `awesome-dsh-plugins` 的可机器读取资料。它将**已核验的可加载 DSH 扩展**与 GitHub 主题页的**未审核候选**严格分开；请不要将候选 CSV 当成推荐或兼容性清单。

This directory stores machine-readable sources for `awesome-dsh-plugins`. It deliberately separates **verified loadable DSH extensions** from **unreviewed discovery candidates** collected from GitHub topics. Do not treat a candidate CSV as a recommendation or a compatibility list.

| 文件 / File | 含义 / Meaning |
| --- | --- |
| `repositories.csv` | **全量聚合目录**：合并 GitHub 搜索（`topic:dsh-plugin` / `topic:deepseek-harness` / 名称搜索）与多个社区目录后去重得到的全部仓库，含描述、星级、许可证、语言、话题与 `verified` 标记。由 `scripts/aggregate.py` 生成。 / **Full aggregated catalog**: every repository merged and deduplicated from GitHub search and several community directories, with description, stars, license, language, topics, and a `verified` flag. Generated by `scripts/aggregate.py`. |
| `verified-plugins.csv` | 主目录使用的核验数据。每一行有项目、分类、安装/挂载线索、许可证、活动日期、风险级别、核验依据与日期；**2026-08-14 起新增 `capability` 与 `caution` 两列**（为 README 表格自动生成提供能力与风险说明）。 / Data behind the main directory: repository, category, install/mount hint, license, activity date, risk level, evidence, inspection date; since 2026-08-14 also carries `capability` and `caution` columns used to generate the README tables. |
| `audit-results.csv` | **批量审计日志**：两轮全量审计共 1363 条记录（首轮 417 个候选 + 主题页新增 946 个候选），2026-08-17 第三轮主题页审计再核验 154 个新增高星候选（>10 星），现共 1516 条记录，含判定、理由、能力、安装命令、许可证、风险、证据。首轮 325 个、第二轮 686 个、第三轮 104 个符合条件者已升入 `verified-plugins.csv`，其余为 watchlist / rejected。 / **Batch audit log**: 1,363 records across two full audits (417 candidates in the first pass + 946 new candidates from the topic refresh), plus a third topic-page audit on 2026-08-17 reviewing 154 new high-star (>10 stars) candidates; 1,516 records total today, each with verdict, reason, capability, install command, license, risk, and evidence. 325 (first pass) + 686 (second pass) + 104 (third pass) qualifying repos were promoted to `verified-plugins.csv`; the rest are watchlist/rejected. |
| `dsh-plugin-topic-candidates.csv` | 从 [GitHub `dsh-plugin` / `deepseek-harness` 主题](https://github.com/topics/dsh-plugin) 分页搜索发现的 **1991 个仓库标识**快照（含各轮审计的判定状态；未审计者标 `unreviewed`）。 / A snapshot of **1,991 repository identifiers** discovered from the GitHub topic search (with verdicts from the audit passes where available; un-audited ones stay `unreviewed`). |
| `curation-criteria.yaml` | 收录范围、可接受 DSH 原生证据、状态和风险分级。 / Inclusion scope, accepted DSH-native evidence, statuses, and risk levels. |
| `topic-snapshot/` | 聚合脚本的输入缓存（GitHub 搜索 JSON、参考目录文件），**不入库**。 / Raw inputs cached by the aggregation script (search JSON, reference catalog files), **not committed**. |

候选快照用于后续审核，而非“全网完整列表”的声明。GitHub topic 内容与排序会变化；维护者应逐项依据 manifest、patch、源码入口和可复现安装路径复核，而不是按数量或 topic 直接收录。

The candidate snapshot is for future review, not a claim of a complete web-wide inventory. GitHub topic content and ordering change. Review each item through manifests, patches, source entry points, and reproducible mounting instructions rather than topic membership or raw counts.
